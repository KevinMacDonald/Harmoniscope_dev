This is a program that demonstrates how to:

- Read in the values of the station knobs.
- Read in the values of the station ID jumper switches.
- Output DMX to control a 3-color can light.

Requires the 'ads1256' library and the 'ads1256-py' wrapper to be installed. 
See their README.txt files in the lib/ directory for instructions.

Run it as root:

  sudo ./station_test.py
